# Computer-Vision-Master-Projects

A collection of five advanced computer vision projects, from classical geometry to face recognition and object detection, completed during my Master's program in Computer Vision at FAU Erlangen-Nürnberg.

## Projects

| Project | Description                                                                                                              | Key techniques |
|---|--------------------------------------------------------------------------------------------------------------------------|---|
| [3D-Box-Detection](./3D-Box-Detection) | Robust estimation of 3D bounding boxes from point cloud and geometric data                                                 | RANSAC, MLESAC, Preemptive RANSAC |
| [Demosaicing-HDR](./Demosaicing-HDR) | Reconstructing full-color images from Bayer-pattern sensor data and merging multiple exposures into HDR images           | Demosaicing, camera response curve estimation, HDR pipeline, iCAM06 tone mapping |
| [Writer-Identification-Retrieval](./Writer-Identification-Retrieval) | Identifying and retrieving historical manuscript writers from handwriting images using the ICDAR2017 dataset             | Bag-of-visual-words, VLAD encoding, generalized max pooling, multi-VLAD, exemplar-SVM |
| [Face-Recognition](./Face-Recognition) | Video-based face detection, tracking, identification, and re-identification, including an open-set recognition challenge | MTCNN detection, template-matching tracking, FaceNet embeddings, k-NN, k-means clustering, open-set recognition (SPL/MPL) |
| [Selective-Search](./Selective-Search) | Region proposal generation and a full object detection pipeline for balloon detection                                    | Selective search (Felzenszwalb segmentation + hierarchical region merging), SVM classification, COCO mAP / MABO evaluation |
